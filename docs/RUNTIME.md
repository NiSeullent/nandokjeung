# RUNTIME.md

## 값 표현

| 내부 | 설명 |
|------|------|
| `Jeong(i64)` | 정수 |
| `Ppyung(String)` | 문자열 |
| `Mental(bool)` | 불리언 |
| `Void` | 없음 |
| `Ipnwon` | 함수 클로저 (v1.0: 이름 기반) |

## Truthiness

- 정수 0 = 거짓
- 빈 문자열 = 거짓
- 나머지 참

## 환경

블록·함수마다 자식 환경. 상위 스코프 체인.

## I/O

- 출력: `행정 ! expr !` → stdout (개행 없음)
- 입력: `? 행정 정신 name !` → 한 줄 읽기

## 예외

`행정 정병 expr !` → `보호`/`정병`으로 catch.

## 내장

- `입원 행정 정신 !` — Unix timestamp % 100000
- `입원 행정 뼝 !` — 난수 0..100
