# TUTORIAL.md — 정신뼝! 입문

## 1. Hello World

```text
행정 ! 저엉신저엉신 <UTF-8 bits> 저엉신저엉신 !
```

`tools/encode_string.py`로 비트 생성.

## 2. 숫자

7 = `멘헤라 뼝 뼝 뼝 멘헤라` (이진 111)

```text
행정 ! 멘헤라 뼝 뼝 뼝 멘헤라 !
```

## 3. 변수

```text
행정 정신 우범 !
뼝 정신 우범 멘헤라 뼝 뼝 뼝 멘헤라 !
행정 ! 정신 우범 !
```

## 4. 조건문

```text
? 멘헤라 입원 멘헤라 멘헤라 자의 행정 ! ... ! 동의 행정 ! ... ! 뼝
```

## 5. 반복

```text
우범 소년 우범 원 멘헤라 뼝 뼝 정신 멘헤라
멘헤라
  행정 ! 정신 우범 !
뼝
```

## 6. 함수

```text
입원 정병
  소년 정신
멘헤라
  행정 뼝 정신 정신 뼝 정신 정신 !
뼝
행정 ! 입원 정병 멘헤라 뼝 뼝 뼝 멘헤라 !
```

## 7. 입력

```text
행정 정신 정신 !
? 행정 정신 정신 !
행정 ! 정신 정신 !
```

## 팁

- 함수 이름에 `뼝` 단독 사용 금지 (블록 종료와 충돌).
- 곱셈은 `원`, 뺄셈은 `정신`, 덧셈은 `뼝`.
- 미선언 변수에 대입 시 암시적 선언됨 (v1.0).
