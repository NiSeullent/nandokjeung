# LANGUAGE.md

정신뼝! 언어 개요. 상세는 [SPEC.md](SPEC.md), 설계는 [../LANGUAGE_DESIGN.md](../LANGUAGE_DESIGN.md).

## 철학

- **정신**: 상태·값
- **뼝**: 변화·실행
- **멘헤라**: 복합 상태(블록)
- **입원**: 영역 진입(함수)
- **행정**: 시스템 명령
- **저엉신저엉신**: 데이터 인코딩

## 왜 이 토큰인가

단순 `if=정신` 치환이 아니라, 토큰 간 **문맥 의존** 문법:

- `멘헤라`는 블록·정수·그룹
- `?`는 AND·입력·if 시작
- `뼝`은 대입·덧셈·블록 종료(단독)
