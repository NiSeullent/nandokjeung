# 정신뼝! Language Specification

**Version 1.0**

## 1. 개요

정신뼝!은 15개 고정 토큰만으로 작성되는 Turing-complete(의도) 난해 언어이다.

## 2. 토큰

| 토큰 | 역할 |
|------|------|
| `정신` | 변수 참조 마커, 비트 0, 뺄셈 |
| `뼝` | 대입·반환 동사, 비트 1, 덧셈 |
| `멘헤라` | 블록·리터럴 래퍼 |
| `입원` | 함수 정의/호출 |
| `자의` | if 참 분기 |
| `동의` | else 분기 |
| `보호` | try |
| `행정` | 선언·출력·시스템 |
| `!` | 문장 종료 |
| `?` | 조건·입력 |
| `우범` | 반복 |
| `소년` | 매개변수·for 변수 |
| `원` | 곱셈·소수 1 |
| `정병` | catch·주석·throw |
| `저엉신저엉신` | 문자열 경계 |

## 3. 문법 요약

- 선언: `행정 정신 <이름> !`
- 대입: `뼝 정신 <이름> <expr> !`
- 출력: `행정 ! <expr> !`
- 입력: `? 행정 정신 <이름> !`
- 정수: `멘헤라 <bit>+ 멘헤라` (MSB first)
- 문자열: `저엉신저엉신 <bit>+ 저엉신저엉신`
- true: `멘헤라 입원 멘헤라` / false: `멘헤라 보호 멘헤라`
- if: `? <cond> 멘헤라 자의 ... 동의 ... 뼝`
- while: `우범 ? <cond> 멘헤라 ... 뼝`
- for: `우범 소년 <v> <start> <end> 멘헤라 ... 뼝`
- 함수: `입원 <name> 소년 <p> 멘헤라 ... 행정 뼝 <expr> ! 뼝`
- 호출: `입원 <name> <arg> !` (v1.0: 인자 1개)
- try: `보호 멘헤라 ... 정병 멘헤라 ... 뼝`

## 4. 연산

| 구문 | 의미 |
|------|------|
| `a 뼝 b` | 덧셈/문자열 연결 |
| `a 정신 b` | 뺄셈 |
| `a 원 b` | 곱셈 |
| `a 멘헤라 우범 b` | `<` |
| `a 멘헤라 소년 b` | `>` |
| `a 멘헤라 자의 b` | `==` |
| `a 멘헤라 동의 b` | `!=` |
| `a ? b` | `&&` |
| `a ? b 동의 c` | `\|\|` |

## 5. 타입 (내부)

정수(`Jeong`), 문자열(`Ppyung`), 불리언(`Mental`), 공허(`Void`), 함수(`Ipnwon`).

## 6. 내장 함수

- `입원 행정 정신 !` — 타임스탬프
- `입원 행정 뼝 !` — 난수 0..100

## 7. 오류 코드

| 코드 | 설명 |
|------|------|
| E000 | Lexer 오류 |
| E001 | 미정의 변수 |
| E002 | 중복 선언 |
| E003 | 타입 오류 |
| E010 | 인자 개수 |
| E040 | 런타임 예외 |

## 8. 구현

Rust 인터프리터. 파이프라인: Lexer → Parser → Semantic → Interpreter.

## 9. 제한 (v1.0)

- 함수 인자 1개
- 일급 함수 미지원
- `뼝` 블록 종료와 `뼝` 대입은 `뼝 정신` 패턴으로 구분
